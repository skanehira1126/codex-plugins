# Abstract Header

テーマを色、質感、構図、空気感のみで表す、洗練された抽象画像を選んだサイズで制作する。
このskillは制作方針と選択の流れを担当する。生成時は利用可能な `imagegen` skillを読み、
実行方法、編集、保存、画像の提示はその手順に従う。利用できない場合は組み込み画像生成ツールの
指示に従う。画像生成機能自体が使えなければ、その旨と作成済みの生成プロンプトを返し、生成済みとは扱わない。

## 1. テーマと配色を確定する

- 会話で指定済みの情報を拾い、未指定の「テーマ」「メインカラー」「アクセントカラー」だけを確認する。
- テーマはユーザーの指定を必須とする。色や用途から勝手に補完しない。指定済みのテーマを再確認する必要はない。
- 色が片方でも未指定なら、テーマ確定後に配色を2〜4案提示する。指定済みの色は固定し、各案にメインカラー、アクセントカラー、短い印象説明（静謐、知的、温かい等）を添える。
- ユーザーが配色案を選ぶまで生成しない。色名でも確定として扱い、HEX指定を必須にしない。
- テーマと両色が確定してから画風の選択へ進む。

## 2. サイズ・画風・パターンを選ぶ

会話で指定済みのサイズ候補名、幅 × 高さ（px）、縦横比を優先し、再確認しない。寸法は幅、高さの順に扱う。
未指定なら次の候補と自由指定ができることを画風の提案に添える。画風が確定済みならサイズの候補だけを示す。

| 選択肢 | 目標サイズ（幅 × 高さ） |
| --- | --- |
| 標準ヘッダー | 1280 × 770 px |
| 横長 16:9 | 1920 × 1080 px |
| 正方形 1:1 | 1080 × 1080 px |
| 縦長 9:16 | 1080 × 1920 px |

候補は生成ツールの対応サイズを保証するものではない。自由指定は正の整数の幅・高さ、または縦横比を受け付ける。
指定が矛盾・不明確な場合だけ確認する。比率のみの指定なら、その比率を目標にツールが対応する解像度を使う。
選択への回答を待つが、画風のみの回答でサイズが省略された場合や「おすすめで」「サイズは任せる」という委任がある場合は、
標準ヘッダーを採用してサイズだけの追加確認はしない。複数案は別指定がなければ同じサイズにそろえる。

画風が未指定なら、[12の画風](references/styles.md)を読み、テーマ・配色・用途に合う4つを提案する。縦横比が指定済みなら、それも考慮する。
「強い質感」「ミニマル／余白」「構造的／知的」「有機的／感性的」をなるべく分散させ、
似た紙質・淡色・有機形状ばかりにならないようにする。各候補に画風名と短い選定理由を添え、最も合う候補を推薦する。

選択は1つ、複数、4つ全部を受け付ける。同じ画風の構図違いも選べると伝える。
指定済みの画風や「おすすめで」という委任がある場合、画風の候補選択のために再度止めない。
推薦は生成許可の代わりにしない。選択も委任もなければ回答を待つ。

- 指定枚数がなければ選択した各画風を1案ずつ生成する。「おすすめで」のみなら最適な画風を1案生成する。
- 同じ画風の複数案は、色とテーマを固定し、重心、流れ、レイヤー密度、余白の位置などを変える。
- 枚数だけが指定され画風の配分が任されていれば、候補から違いの出る配分を決める。
- 枚数と選択画風が矛盾する場合だけ、配分を確認する。
- 4つは提案数であり生成枚数の上限ではない。12画風すべての指定や追加案も受け付ける。

## 3. 生成する

確定したテーマ・配色・サイズまたは縦横比・画風・各案の構図を生成プロンプトへ組み込む。
ツールに対応するサイズ指定引数があれば設定し、未対応の引数は作らない。
選択画風の指示は [styles.md](references/styles.md) を参照する。
複数案ではテーマと配色を共通に保ち、画風・質感・構図・余白の違いを明確にする。
比較用の分割画像にまとめず、各案を独立した画像として制作する。

共通要件:

- 確定したメインカラーとアクセントカラーを軸に、彩度・明度・コントラスト・色の面積比はテーマとユーザーの意図に合わせる。低彩度、淡色、少量のアクセントを一律に求めない。鮮やかな色や強い対比も使える。補助色はテーマに応じて取り入れ、指定された配色や色数の制約を守る。
- 詩的で非具象的、上品で深みのある仕上がりにする。静けさや内省に限定せず、躍動感、喜び、緊張感などテーマの印象を構図と質感にも反映する。
- 人物、顔、識別できる物体、文字、ロゴ、意味を持つ記号、アイコン、図解、具体的な風景は含めない。幾何学的な線・円・色面は抽象構成として使える。
- 強い3Dレンダリング感、強すぎる光沢、説明的な構図、安価なストック画像風の表現を避ける。発光はテーマに必要な範囲で使い、質感や構図を覆い隠す装飾にしない。
- 選んだ縦横比に合わせて重心、流れ、余白を設計し、指定寸法がなければ対応範囲で高解像度にする。文字を置く位置が指定されていれば、その領域を静かに保つ。画像内には文字を生成しない。
- ツールが目標寸法・比率に対応しなければ近い比率で生成し、実際の寸法を確認して差を伝える。厳密な納品寸法が必要なら、その調整は利用可能な画像編集手順とユーザーの指示に従う。未確認の寸法を保証せず、寸法を確認できない場合はその旨を伝える。

plugin独自の総生成枚数や「1枚生成後は追加指示を待つ」という制限は設けない。
一度の依頼で選ばれた全案を生成する。呼び出し単位や同時実行可否は `imagegen` と利用可能なツールに従い、
未対応の一括生成引数を作らない。サービスの利用上限は解除できないため、無制限とは案内しない。
途中で上限や失敗に達したら、完成した案と未生成の案を示し、自動で繰り返し再試行しない。

## 4. 確認して提示する

各画像を確認し、配色、画風の差、非具象性、余白、寸法を点検する。
選択した画風との対応が分かる短いラベルで画像を提示する。画像内へラベルを書き込まない。
違反や未達があれば対象を絞って修正し、残る制約は明示する。
完成した案から、同じテーマ・配色を引き継いだ画風変更や構図調整、サイズ変更を受け付ける。
サイズ変更の指定がなければ確定済みのサイズを引き継ぐ。
