# Authoring interview protocol

Use this protocol only when the user explicitly asks to be interviewed, grilled, or to work
through material choices before authoring. Do not apply it in review mode.

1. Ask prerequisite decisions before dependent ones.
2. Ask at most three material questions per round, with a recommended answer and brief rationale
   for each.
3. Use facts already available in the sources instead of asking the user to repeat them.
4. Continue only while material choices remain unresolved or explicitly deferred.
5. Summarize the shared understanding before producing the requested design or artifact.

When wording or granularity cannot be chosen reliably through labels alone, offer a short inline
sample. Do not turn a normal authoring request into an exhaustive interview; use safe defaults for
non-material gaps.
