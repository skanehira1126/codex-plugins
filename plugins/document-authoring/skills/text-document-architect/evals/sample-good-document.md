# 来期は分析人材の増員より、案件受付と実装責任の標準化を優先する

## 経営会議では、3部署での8週間の試行開始を承認してほしい

- 認知動作: 判断
- 抽象度: 具体

求める判断は、案件受付票、実装責任者、効果測定方法を共通化する試行の開始である。対象を限定した可逆的な試行とし、継続投資は結果を見て判断する。

## 案件の停滞は、分析工程より着手前と実装前に集中している

- 認知動作: 観察
- 抽象度: 具体

対象案件の滞留記録では、分析作業そのものより、要件確定と実装責任者の決定に待ち時間が集中していた。出典：2026年4〜6月の社内案件管理ログ。

## ボトルネックは人員数ではなく、案件を成果まで運ぶ責任分界にある

- 認知動作: 再解釈
- 抽象度: 混在

当初は分析人材の不足を主因と想定していた。しかし前節の観察から、増員だけでは着手前と実装前の滞留を解消できない。したがって、来期の最初の介入は人員追加ではなく、案件形成プロセスの標準化である。

## 試行では実装率と効果捕捉率を測り、継続・修正・停止を判断する

- 認知動作: 行動
- 抽象度: 具体

責任者はデータ活用推進室とし、各部署の案件責任者を試行開始前に確定する。評価時点では、分析件数ではなく実装率、効果捕捉率、案件当たりの滞留日数を比較し、次の投資判断へつなげる。
