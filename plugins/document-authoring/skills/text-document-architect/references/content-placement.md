# テキスト文書の情報配置

候補情報を本文へ展開する前に、置き場所を決める。

## 本文

削除すると対象読者が次を行えなくなる情報は本文へ置く。

- 中心命題、支配的な目的、または作業を理解する。
- 因果・手順の論理を追う。
- 主要主張または判断を評価する。
- 重大なリスク・制約を認識する。
- 求められた行動を実行する。

本文は「全情報」ではなく、読者の主経路である。

## 表・コールアウト

重要だが、文章で順番に追うより走査した方が理解しやすい情報に使う。

- 構造化された比較
- 定義の集合
- 判断基準
- 役割、日付、統制の要約
- 抽象的な章を具体へつなぐ事例
- 本文中で一度立ち止まるべき結論・注意点

すべてをカードや囲みへ変えない。視覚的な分離は、内容の機能を反映させる。

## 脚注・注記

その瞬間の理解には不要だが、追跡可能性や限定条件として残す情報に使う。

- 出典の詳細
- 狭い方法論上の注意
- 用語の由来
- 二次的な例外

結論、解釈、作業結果を変える事実を、脚注へ追いやらない。

## Appendix

本文の主経路には不要だが、検証、再利用、専門的な深掘りに有用な情報に使う。

- 詳細な方法
- 完全な表、ロバストネス確認
- 拡張事例
- 用語集、データ辞書
- 歴史的背景
- 二次読者向けの実装詳細

Appendixの章名は、答える問いまたは含む資料が分かるものにする。必要に応じて本文から参照する。

## 削除

次の情報は削除する。

- 重複している。
- 根拠がない。
- 元資料に含まれていたという理由だけで残っている。
- 理解や行動を変えるには弱すぎる。
- 検索・再利用の価値もない装飾的な背景である。

## 配置テスト

各候補情報について、次の順で問う。

1. 削ると主な理解、判断、作業が変わるか。→ **本文**
2. 重要だが、文章より構造化して見せた方がよいか。→ **表・コールアウト**
3. 流れを止めずに追跡可能性・限定条件を残す情報か。→ **注記**
4. 検証または専門的な深掘りに有用か。→ **Appendix**
5. それ以外。→ **削除**

## 安全規則

- 結論、解釈、作業結果を変え得るリスク・前提・制約は本文に置く。
- Appendixへ移した結果、本文の主張が無根拠にならないようにする。
- 表へ移した結果、重要な解釈を読者に任せない。
- 注記へ移した結果、数値の定義や対象範囲が分からなくならないようにする。
