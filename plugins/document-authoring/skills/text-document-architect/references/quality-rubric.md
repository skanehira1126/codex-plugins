# テキスト文書の品質評価基準

アウトライン作成後と成果物生成後に、各評価軸を0〜2点で採点する。

| 評価軸 | 0 — 不合格 | 1 — 一部達成 | 2 — 強い |
|---|---|---|---|
| 1. 目的と読み方の契約 | 読者、用途、期待結果が不明 | 目的はあるが、読み方や利用場面を暗黙に仮定している | 読者、利用場面、期待結果、profileに合う読解または検索の契約が明確 |
| 2. 支配的な目的 | 話題だけ、または競合する目的が複数ある | 中心命題や目的はあるが広すぎる、または埋もれている | 一つの具体的な中心命題または支配的な目的が情報選択を統制している |
| 3. content mapの一貫性 | 論点・規則・手順の一覧だけで、必要な関係がない | 多くの接続は推測できるが、一部を読者が補う | profileに必要な主張、根拠、適用、順序、分岐、例外、結果が明示的につながる |
| 4. 読者動作または検索経路 | sequential / learningで抽象的な説明が続く、またはlookup/referenceで入口と分岐が不明 | 読み進められる、または検索できるが、一部に平板さや迷いが残る | profileに合う認知動作または予測可能な検索経路がある |
| 5. 抽象と具体 | 概念が経験、根拠、適用から切り離されている | 事例はあるが、置くタイミングが弱い | 具体と抽象が有効な間隔で相互補強する |
| 6. 対象読者の理解可能性 | 必要な前提を読者が補っている | 用語は概ね説明されるが、全体像やメンタルモデルが弱い | 指定した対象読者が、用途に必要な正しいメンタルモデルを作れる |
| 7. 根拠と確度 | 主張、規則、手順が無根拠、捏造、または過剰に断定的 | 根拠や適用条件はあるが遠い、または但し書きが弱い | 必要な根拠、契約、適用条件を追跡でき、確信度が支持の強さに合う |
| 8. 情報配置と認知的な経済性 | 本文にすべてを詰め込む、または重要情報を別の場所に隠す | 一部は移動されるが、密度が不均衡 | 本文、表、注記、Appendix、削除を読者の必要性で選ぶ |
| 9. ナビゲーションと走査性 | 見出し、参照、構造が検索・再訪を支えない | 使えるが、汎用的または不統一 | 見出しが意味を持ち、長さと用途に合うナビゲーションがある |
| 10. 成果物品質 | ファイルが壊れている、利用不能、未検証 | 利用可能だが軽微な欠陥がある | 指定された成果物が清潔で、用途に適し、必要な検証を通っている |

## 合格規則

- 合否は、合計点ではなく、下記のハードゲートで判断する。
- 評価軸1〜8は必須で、0点を許容しない。
- 合計点は校正済みの客観指標ではなく、同じ評価者・条件で改訂前後を比較するための参考値とする。
- 粗い草稿が明示的に求められた場合だけ、草稿であることを明記して低い点数を許容する。

点数を上げるために文章量を増やさない。まず、選択、順序、関係、具体的な足場、根拠、ナビゲーション、配置を改善する。

## ハードゲート

次のいずれかに該当する場合、修正するまで不合格とする。

- タイトルと見出しを走査しても、中心命題または支配的な目的を言えない。
- sequential / learningで、観察、事例、再解釈、適用、判断を挟まず、抽象的な説明が長く続く。
- lookup/referenceで、代表的な利用作業から適用範囲、規則・手順、分岐、例外、失敗時の扱いへ到達できない。
- 必須の用語、因果、前提、適用条件を読者が補っている。
- 主要主張に根拠または適切な不確実性表示がない、または規則・手順の根拠となる契約を追跡できない。
- 結論、解釈、作業結果を変え得る但し書きが、注記やAppendixへ埋められている。
- sequential / learningの結びが具体的な含意、判断、行動、冒頭の問いへ戻らず一般論で終わる、またはlookup/referenceに必要な結果・復旧・関連参照がない。
- レンダリング後の成果物に、文字切れ、表崩れ、不自然な改ページ、利用不能なナビゲーションがある。
- 改訂対象の編集可能な構造や、依頼で必要とされた原本が失われている。

## 指摘の重大度

- **致命的**：誤った判断、適用、作業、事実誤認、無根拠な信頼につながる可能性が高い。
- **重大**：論理や検索経路の復元コスト、疲労、支配的な目的の喪失を大きく増やす。
- **軽微**：局所的な明瞭さ、表現、整合性、仕上げの問題。
