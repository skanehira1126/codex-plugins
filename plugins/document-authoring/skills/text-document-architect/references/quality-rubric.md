# テキスト文書の品質評価基準

アウトライン作成後と成果物生成後に、各評価軸を0〜2点で採点する。

| 評価軸 | 0 — 不合格 | 1 — 一部達成 | 2 — 強い |
|---|---|---|---|
| 1. 目的と読み方の契約 | 読者、用途、期待結果が不明 | 目的はあるが、読み方や利用場面を暗黙に仮定している | 読者、利用場面、A→B、ナビゲーションの契約が明確 |
| 2. 中心命題 | 話題だけ、または競合する主張が複数ある | 中心命題はあるが広すぎる、または埋もれている | 一つの具体的な中心命題または支配的な目的が情報選択を統制している |
| 3. 論証と一貫性 | 論点一覧、飛躍、無根拠な接続がある | 多くの接続は推測できるが、一部を読者が補う | 主張、根拠、推論、反論、含意が明示的につながる |
| 4. 読者動作のメリハリ | 同じ抽象的な説明・断定が長く続く | 一部に変化はあるが、平板な区間が残る | 論理を保ちながら、認知動作が意味に沿って変化する |
| 5. 抽象と具体 | 概念が経験、根拠、適用から切り離されている | 事例はあるが、置くタイミングが弱い | 具体と抽象が有効な間隔で相互補強する |
| 6. 初見読者の理解可能性 | 必要な前提を読者が補っている | 用語は概ね説明されるが、全体像やメンタルモデルが弱い | 前提知識が一段少ない読者でも正しいメンタルモデルを作れる |
| 7. 根拠と確度 | 主張が無根拠、捏造、過剰に断定的 | 根拠はあるが遠い、または但し書きが弱い | 根拠を追跡でき、確信度が支持の強さに合う |
| 8. 情報配置と認知的な経済性 | 本文にすべてを詰め込む、または重要情報を別の場所に隠す | 一部は移動されるが、密度が不均衡 | 本文、表、注記、Appendix、削除を読者の必要性で選ぶ |
| 9. ナビゲーションと走査性 | 見出し、参照、構造が検索・再訪を支えない | 使えるが、汎用的または不統一 | 見出しが意味を持ち、長さと用途に合うナビゲーションがある |
| 10. 成果物品質 | ファイルが壊れている、利用不能、未検証 | 利用可能だが軽微な欠陥がある | 編集可能な原本と配布物が清潔で、用途に適し、検証済み |

## 合格規則

- 合否は、合計点ではなく、下記のハードゲートで判断する。
- 評価軸1〜8は必須で、0点を許容しない。
- 合計点は校正済みの客観指標ではなく、同じ評価者・条件で改訂前後を比較するための参考値とする。
- 16/20点は改善目標に限って使い、ハードゲートの代わりにしない。
- 粗い草稿が明示的に求められた場合だけ、草稿であることを明記して低い点数を許容する。

点数を上げるために文章量を増やさない。まず、選択、順序、関係、具体的な足場、根拠、ナビゲーション、配置を改善する。

## ハードゲート

次のいずれかに該当する場合、修正するまで不合格とする。

- 設計・作成モードで、文書を大きく変えるユーザー判断を安全な既定値として黙って補い、解消または明示的な保留なしに本文を作成している。
- タイトルと見出しを走査しても、目的または中心命題を言えない。
- 連続読解型の文書で、観察、事例、再解釈、適用、判断を挟まず、抽象的な説明が長く続く。
- 必須の用語、因果、前提を読者が補っている。
- 主要主張に根拠または適切な不確実性表示がない。
- 結論を変え得る但し書きが、注記やAppendixへ埋められている。
- 結びが具体的な含意、判断、行動、冒頭の問いへ戻らず、一般論で終わる。
- レンダリング後の成果物に、文字切れ、表崩れ、不自然な改ページ、利用不能なナビゲーションがある。
- 編集可能な原本が必要なのに、PDFまたは画像だけが残る。

## 指摘の重大度

- **致命的**：誤った判断、事実誤認、無根拠な信頼につながる可能性が高い。
- **重大**：論理の復元コスト、疲労、中心命題の喪失を大きく増やす。
- **軽微**：局所的な明瞭さ、表現、整合性、仕上げの問題。
