# 文章中心の文書における認知的なメリハリ

## ここでいう「メリハリ」

認知的なメリハリとは、文の長さや口調を装飾的に変えることではなく、**読者の頭に求める処理を変えること**である。

主な認知動作：

- **状況把握**：状況、範囲、主体、全体図をつかむ。
- **問い**：不足、対立、異常、判断すべき点に気づく。
- **観察**：事例、出来事、データ、具体的な現象を見る。
- **説明**：仕組み、定義、因果を理解する。
- **再解釈**：それまでの見方を更新する。
- **評価**：根拠、選択肢、基準、不確実性を比較する。
- **判断／行動**：選択する、適用する、実行する。
- **統合**：新しいモデルを全体へつなぎ直す。

文書が「高密度のっぺり」になるのは、抽象的な断定を受け取る処理だけを、読者に繰り返し求めるときである。

## 有用な問いを一つ開き、人工的なサスペンスは作らない

具体的で未解決の問いは、先を読む理由になる。問いが働くのは、読者に関係し、範囲が限定され、続く内容で答えられるときである。

- 連続する解説に有効：「分析人材を増やしても、実装案件が増えないのはなぜか」
- 意思決定文書で不適切：推奨案そのものを最後まで隠す。
- どの媒体でも不適切：すぐ自分で答えるだけの修辞疑問を装飾として置く。

意思決定文書では結論を早く示し、その正当化を開いた問いとして残す。

## 断定、不確実性、認識の更新

人間らしく見せるためだけの演出的なためらいを入れない。確信度の変化は、実際の推論経路を反映させる。

```text
初期仮説 → 観察された根拠 → 修正された解釈
```

この流れは、正当な認知的転換を作り、なぜ確信したかを可視化する。

## 導入

話題だけを並べる中立的な議題表から始めない。文書の仕事に応じ、次のいずれかから始める。

- 役員向け・意思決定文書：判断または結論
- 提案・解説：認識しやすい実務上の摩擦
- 分析報告：重要な発見または異常
- 業務参照：全体マップと利用者の作業

目次はナビゲーションを支える場合に有用である。「A、B、Cを扱う」と予告するだけなら弱い。

## 読者が必要とした時点で概念を導入する

解説・学習文書では、次の流れを基本とする。

```text
具体的な問題 → 現在の理解では説明できない点 → 概念名 → 仕組み → 適用
```

規程、仕様書、参照文書では、検索性と一貫性が物語的発見より重要なため、定義を先に置いてよい。

## 箇条書きには解釈が必要

箇条書きは、本当に並列な項目に使う。項目間の関係が重要な場合は、文章または視覚構造で次を示す。

- どれが主要か。
- 何が何を引き起こすか。
- 何を先に行うか。
- どれが代替案か。
- 直前の事例や判断とどうつながるか。

整って見える箇条書きでも、認知的には未完成であり得る。

## 文章の実況を削り、有用な案内を残す

書いている行為だけを報告する表現は削る。

- 「次に説明します」
- 「ここまで見てきたように」
- 「本節では三つを扱います」

一方、アイデア間の関係を示す案内は残す、または関係が明確になるよう書き換える。

- 「後ろ二つの課題は、一つ目の責任分界の曖昧さから生じている。」
- 「この結果は平均値では見えないため、次に部署別の分布を確認する。」

## 水増しせずに密度の波を作る

高密度の説明・根拠の後には、目的を持つ低密度の動作を置く。

- 具体例
- 一文の統合
- 図・表
- 含意
- 比較
- 適用上の問い

何も増やさない「休憩文」を挿入しない。余白や短い段落は、スタイル模倣ではなく理解を支えるために使う。

## 結び

強い結びは次を行う。

1. 冒頭の問い、経験、判断へ戻る。
2. 読者のモデルが何から何へ変わったかを示す。
3. 具体的な行動、判断基準、範囲の限られた次の問いを残す。

具体的な含意があるのに、誰も反対しない抽象論で終えない。

## メリハリ監査

各主要セクションに主な認知動作を付け、並びだけを読む。次を調べる。

- **説明／断定**が長く連続している。
- 具体的な足場なしに、抽象的な章が複数続く。
- 主張と根拠の段落が繰り返され、統合や含意がない。
- すべての章が同じ長さ・内部形状である。
- 不確実性が、解釈へ影響する箇所ではなく最後にまとめて書かれている。
