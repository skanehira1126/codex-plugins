# 文書設計メモ

設計を共有する場合に、必要な項目だけ使う。短い文書は数行でまとめてよい。

## 目的と条件

- 読者と前提知識：
- 読んで分かること・できること：
- 主な読み方と、必要なら補助の参照経路：
- 指定形式、長さ、文体、必須内容：
- 確認できていない条件と影響：
