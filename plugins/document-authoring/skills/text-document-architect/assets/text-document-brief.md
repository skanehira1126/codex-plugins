## 成功ゲート

- [ ] 走査しただけで、中心命題または支配的な目的が分かる。
- [ ] 見出しが使える地図になっている。
- [ ] sequential / learningでは、読者動作が説明だけに偏っていない。
- [ ] lookup/referenceでは、代表的な作業から規則、分岐、例外、失敗時の扱いへ到達できる。
- [ ] 初見読者に必要な前提が与えられている。
- [ ] 主要な主張、規則、手順の根拠、適用条件、確度を必要に応じて追跡できる。
- [ ] 結論または作業結果を変え得る制約が主経路にある。
- [ ] 編集可能な原本の扱いが決まっている。
- [ ] 最終成果物をレンダリングまたはプレビューする。
