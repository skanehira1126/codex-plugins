# 文書設計メモ

設計を共有する場合に、必要な項目だけ使う。短い文書は数行でまとめてよい。

## 目的と条件

- 読者、使う場面、前提知識：
- 書き手の立場、読者との関係、語調の基準（指定・既存文書など）：
- 読んで分かること・できること：
- 初めて読むときに必要な理解：
- 後から参照する場面・疑問・作業（ある場合）：
- 指定形式、長さ、文体、必須内容：
- 確認できていない条件と影響：

## 記載する内容

- 伝える答え・主張・事実と、その根拠・出典：
- 各内容と一緒に残す対象・条件・例外・数値：
- 確度、不明な点、省く情報：

## 構成への配置

| 見出し・入口 | 読者の問い・作業 | 配置する答えと条件 | 読む順序・参照先 |
|---|---|---|---|
|  |  |  |  |

## 配置と確認

- 本文に必要な説明・重要な制約：
- 表・注記・付録・参照先へ置く内容：
- 根拠の不足と残る不確実性：
- 構成の確認結果（想定した読み方で使えるか）：
- 内容の照合結果（原資料との不足・意味変更・根拠のない補完）：
- 残る表現・成果物の確認：
