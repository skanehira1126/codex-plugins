## ゲート結果

選択したprofileに該当する項目だけを確認する。

- [ ] タイトルと見出しから、目的または中心命題が分かる。
- [ ] 章間の接続に、読者が補う因果や前提がない。
- [ ] 連続する章の認知動作が、意味に沿って変化している。
- [ ] 抽象的な章に、事例、根拠、適用、統合のいずれかがある。
- [ ] 開いた問いは有用で、適切な位置で解消される。
- [ ] 参照用途を除き、概念は読者が必要性を持った後に登場する。
- [ ] 箇条書きに、必要な関係・優先順位・解釈が付いている。
- [ ] 結びが、具体的な問い、判断、行動へ戻っている。
- [ ] lookup/referenceでは、代表的な作業から適用範囲、分岐、例外、失敗時の扱いへ順読せず到達できる。
