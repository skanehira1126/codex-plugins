# Agent Coordination

実装をサブエージェントへ段階的に委譲しながら、メインの会話で設計や方針の議論を続けるためのプラグインです。自動では起動せず、明示的に呼び出した作業段階だけを対象にします。

## インストール

```bash
codex plugin add agent-coordination@codex-plugins
```

## `delegate-work-in-stages`

現在承認されている実装段階を、境界の明確な作業としてサブエージェントへ委譲します。メインエージェントは会話、作業範囲、統合後の品質に責任を持ちます。

### 複数のサブエージェントを使う条件

通常は1人へ委譲します。複数人へ並行して委譲するのは、担当ファイルや生成物が重ならず、それぞれの作業が独立して有用だと高い確度で判断できる場合だけです。共有ファイルの編集や、片方の変更に依存する作業は直列に進めます。

### 会話中のcheckpoint

委譲した作業が終わると、メインの会話へ次を簡潔に差し込みます。

- 完了した内容と検証結果
- 現在の議論や判断を変える発見
- 必要な場合は、次に委譲する具体的な作業

次の段階は自動で始めません。通常の会話で承認を受けた後に、改めてサブエージェントへ委譲します。独立した別作業が実行中でも、完了した作業が重要な判断材料になった時点でcheckpointを出せます。

### 向いている依頼

- 実装を任せている間も、メインの会話で設計を詰めたい
- 独立した複数の変更を、ファイル所有権を分けて並行実装したい
- 各段階の完了後に結果を確認し、次の作業を相談して決めたい

```text
$agent-coordination:delegate-work-in-stages を使って、
この実装をサブエージェントへ委譲し、この会話では次の設計を議論してください。
```

!!! warning
    自律的な多段実行、所有権が曖昧な並行編集、別のユーザー所有タスクの作成には使いません。
