# Abstractum

abstractとmuseumの造語。テーマを色・質感・構図・空気感のみで表現する、抽象ヘッダー画像の制作プラグインです。
人物・物体・文字・ロゴを入れず、上品で洗練されたビジュアルを選んだサイズで作ります。

## 使い方

自動呼び出しは無効です。使うときだけ `$abstractum:abstract-header` を明示してください。

```text
$abstractum:abstract-header
テーマは「静かな変化」。メインカラーは紺、アクセントカラーは銅色。
画風を提案して、複数パターンから選びたい。
```

テーマが未指定なら確認し、配色が未指定なら2〜4案を提案します。
3項目が確定すると、12画風から相性のよい4候補を理由付きで提示します。
1つ、複数、全部の選択が可能で、「おすすめで」と任せることもできます。

画風は厚塗りアクリル、油彩、水墨・インク、幾何学ハードエッジ、ミッドセンチュリー・モダン、
紙コラージュ、鉱物・地層・石、半透明デジタルグラデーション、リソグラフ・版画、織物・繊維、
フォトグラム・光、フレスコ・漆喰です。

色はテーマと指定配色を優先し、低彩度や淡色に限定しません。鮮やかな色、強い対比、
存在感のあるアクセントも使えます。フレスコも色をくすませることを必須にせず、漆喰の質感で表現します。

```text
水墨と幾何学の2つで作って。
```

```text
幾何学の画風で、構図を変えて3案作って。
```

選択した全案を独立した画像として制作します。plugin独自の枚数上限はありませんが、
画像生成機能の利用上限や呼び出し仕様には従います。画像生成機能が利用できる環境が必要です。

サイズが未指定なら、画風とあわせて次の候補を提示します。幅 × 高さ（px）や縦横比の自由指定もできます。

| 選択肢 | 目標サイズ（幅 × 高さ） |
| --- | --- |
| 標準ヘッダー | 1280 × 770 px |
| 横長 16:9 | 1920 × 1080 px |
| 正方形 1:1 | 1080 × 1080 px |
| 縦長 9:16 | 1080 × 1920 px |

```text
正方形で、水墨と幾何学の2つを作って。
```

```text
サイズは1500 × 500 px。幾何学の画風で構図違いを3案作って。
```

画風だけを選んだ場合や「おすすめで」と任せた場合は、標準ヘッダーを使います。
指定済みのサイズがあればそれを優先し、複数案や追加の構図調整にも引き継ぎます。
候補は目標寸法です。ツールが厳密な寸法・比率に対応しない場合は、
近い比率で生成し、確認できた実際の寸法と差を伝えます。

## 導入

marketplace登録後にインストールします。登録方法は[導入手順](../getting-started.md)を参照してください。

```bash
codex plugin add abstractum@codex-plugins
```
